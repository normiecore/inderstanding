Skill Tree Sketches

Ten multiple choice questions light up parts of a tree of frameworks, ideas and practices from many traditions. Below are several ways the same tree could be drawn.

Every display uses the same answers and the same content. Answer the questions yourself, or keep the example answers, then switch between displays to compare them. Select any node to see why it is highlighted.

How it works

The same for every display.

  1. 1

    Ten questions

    Multiple choice, about two minutes. None of them asks you to commit to a belief.

  2. 2

    Six branches pull

    Each answer pulls toward one or more branches. A branch is a question people live with, not a religion.

  3. 3

    Some nodes light up

    Three places to start, up to nine more that fit, one stretch, and less familiar doors into what you grew up with.

  4. 4

    You try things

    Every node has something to do. You mark it Heard of it, Tried it or Kept it.

  5. 5

    The tree fills in

    Progress comes only from what you did. The questions only choose where to start.
